- 本轮新增实质故障测试：负数流水插入失败后，余额、操作、幂等请求全部回滚；使用相同请求标记恢复重试后只扣一次。审计插入失败后，话题管理修改也回滚。普通账号伪造管理员ID请求被拒绝。

## 浏览器验收

为避免污染开发库，浏览器使用本次新建的 `inrole_verify_` 隔离库、独立随机密钥及3101端口。测试内容明确标记“隔离验收”，收尾删除本次测试库；用户预览使用3100端口和本机开发库。

- 普通账号登录 → 原版布局首页 → 给实际贴主赠3通宝 → 钱包10→7，出现赠送账号及−3流水。
- 人物投币确认后核对实际结果：牛顿收到1通宝，钱包7→6，出现投给牛顿的−1流水。一次后续定位快捷按钮失败，不将其算作额外投币；以数据库返回的页面和流水为验收结果。
- 普通账号打开管理页显示403对应的管理员权限提示。
- 管理员登录 → 填写新话题 → 站内确认表单填写原因 → 保存 → 页面出现新话题和对应审计记录。
- 个人中心显示真实账号、喜好、余额和内容标签页。
- 1440×1000桌面和390×844手机视口检查，页面内容宽度等于实际clientWidth（滚动条占用宽度）；无横向溢出。截图位于`screenshots/s12-s15-stage/`。
