更新：2026-11-23。S01～S06、前端内容扩展及现代配色/主题/语言/阅读设置已完成本机演示。/admin、头像后台上传、真实改密、真实认证、云媒体和数据库尚未接入。

## 导航与布局

- 手机：底部“帖子 / 热搜 / 人物 / 我的”；电脑：侧边导航；平板按可用宽度自适应。
- 首页已替换S01启动页，推荐/最新展示示例与本机内容。推荐目前为演示排序，不假称已按喜好推荐。
- 页面适配360、390、768、1440像素宽度。表单有标签，按钮有焦点，弹窗支持键盘退出和焦点返回。
- 人物名称与@账号是两个不同链接。弹窗使用可滚动布局和动态视口高度；真实手机软键盘仍需在S16实机验收。

## 公共交互组件

| 组件 | 内容 | 规则 |
| --- | --- | --- |
| 发帖弹窗 | 本次人物、话题、正文、图片/视频、投票、引用、发布 | 登录后使用；失败留草稿；正文与附件都空不可发布 |
| 人物选择器 | 搜索、分类、最近使用、当前选择 | 公共库，不创建角色；切换不丢正文 |
| 登录提示 | 登录、注册入口 | 保留站内目标，不自动完成互动 |
| 评论表单 | 先展示评论；点击写评论后弹出独立人物选择与正文 | 不永久继承作者或帖子人物；关闭保留草稿 |
| 分享弹窗 | 复制文案、系统分享、本机链接说明 | 登录后使用；不自动发送给任何平台 |
| 账号菜单 | 个人中心、公开主页、钱包、喜好、设置、主题快捷切换、退出 | 手机右上、电脑左下；游客仅外观设置；支持键盘和Esc |
| 评分表单 | 1～5分、可选评价 | 按账号保存一份，可修改 |
| 投币弹窗 | 人物、数量、余额、确认 | 登录后使用；不足余额不提交；真实结果来自服务端 |
| 赠送通宝弹窗 | 实际贴主@账号、原文摘要、数量、余额、确认 | 登录后使用；禁止自赠与超余额；双方钱包流水与帖子收到数量同步 |
| 举报表单 | 目标、原因、提交状态 | 需登录，详情不公开 |

## 核心路径

1. 游客：首页→点击评论数量→帖子详情评论区（可直接阅读）→点写评论→登录/注册→喜好引导（新用户）→回帖详情→手动评论。
2. 老用户：登录→有未完成引导则继续，否则回目标页→正常互动。
3. 新用户：注册→喜好1～5项或明确跳过→保存完成状态→推荐首页。
4. 发帖：入口→选人物→写正文/话题→确认→详情；再次换人物不影响旧帖。
5. 评价/投币：人物页→登录（如需）→回人物页→主动确认→统计/余额更新。
6. 赠送：帖子工具栏→登录（如需）→重新点击赠送→确认贴主@账号和数量→扣减本人余额、贴主收到通宝→双方钱包可核对原帖流水。

每页都需要加载、空数据、失败与无权限等实际适用状态，不用假的成功提示代替实现。
