日期：2026-11-22。任务范围：响应式假数据首页；ID+密码、喜好选择的明确演示流程。

- 首页替换S01启动页：桌面左导航、帖子区、右侧发现栏；手机顶栏和底部四项导航。

- 通用组件：品牌、图标、头像、社区框架、帖子卡片、认证框架与表单。

## 账号演示边界

- 只需要ID和密码，无邮箱、手机号。ID去空白、转小写，3～20位字母数字下划线。
- ID唯一性仅在本机当前浏览器的演示资料内有效，不是服务器全局唯一性。
- 密码只在React表单状态中做8～64字符格式检查；不传入账号存储函数，不保存哈希或明文，也不做真实密码验证。
- 演示账号只保存handle、interests、onboardingComplete。资料放localStorage，当前演示身份放sessionStorage。
- 登录只能选择本机已有演示ID，任意满足格式的演示密码均可，页面明确说明。
- 该机制仅用于原型，不能用来保护生产数据。真正注册、会话、授权、密码哈希在S07～S09实现。
- 游客点击发言、点赞、评论会进入登录，保留站内回跳；登录后不自动完成互动。
- 已登录的发帖/点赞/评论暂禁用，注明在S04开放；没有增加虚假的互动数量。

## 你可以复验

1. 打开http://localhost:3000，切推荐/最新，筛选话题并搜索。
2. 游客点击帖子点赞，进入登录；点“注册一个ID”。
3. 填一个新的演示ID、任意8～64字符的非真实密码，进入喜好页。
4. 选最多5项或跳过，返回原帖；进入“我的”查看保存的喜好。
5. 退出后重新用该ID体验登录，注意这不是密码身份验证。
