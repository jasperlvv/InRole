# 发帖与评论人物选择收尾

日期：2026-11-26（北京时间）。

## 修改

- 真实发帖、引用发帖与评论共用 `LivePersonPicker`，以头像、姓名和分类卡片代替文字下拉框；选中后保留头像与姓名，可展开更换。
- 输入人物名字、别名或介绍时，250ms 防抖查询已有真实人物接口，取消过时请求；支持分页加载、无匹配提示、失败重试。搜索覆盖公共人物库，不限于预先载入的前50位。
- 发帖仍展示已加载人物中的最近使用标记；从人物页进入或恢复草稿时可按ID读取选中人物。搜索回车不触发发帖，人物按钮均为 `type="button"`，未选人物禁止提交。
- 两处均提供“找不到？现在申请”，指向真实 `/live/request`，使用已有申请和管理员审核流程。
- 移除真实热搜页的“这份榜单怎样计算？”展开说明。
- 手机使用两列人物卡，380px以下单列，面板可滚动；复用当前主题变量和头像加载失败占位。支持Tab聚焦、按钮选中状态和Escape收起。
