## 2. Git 与 GitHub 的安排

Git 在本机记录版本，用来比较修改、恢复代码。GitHub 保存远程仓库，用于异机取回代码、三人协作和自动检查。按最新安排暂缓托管；之后准备同步时，先做首次提交，再上传 GitHub 私有仓库。上传代码不会自动把社区上线，也不会备份浏览器里的演示账号、帖子、附件或未来数据库。

建议仓库名：`inrole`，先设为 Private，由你持有仓库，按职责邀请 A、B。无需让 B 为整理人物资料而拥有部署密钥。

| 纳入代码仓库 | 不纳入代码仓库 |
| --- | --- |
| `src`、`public`、`tests`、配置与锁文件、AGENTS、README、必要产品/计划/验收文档 | `node_modules`、`.next`、缓存、临时日志、`.env.local`、真实连接串和密钥、数据库备份 |
| 人物资料与头像来源记录、可重复执行的迁移与种子、CI 配置 | `docs/presentation/.build/`、`.codex-finalizer-v4/` 等 PPT 临时构建与验证文件 |

现有 `.gitignore` 已排除依赖、Next 构建和多数环境变量，但首次提交前仍需检查 PPT 临时目录。忽略文件只是不上传，不删除本地文件。最终 PPT 可另作课程资料保存；网站运行不依赖它。

首次备份流程：

1. Codex 检查待提交文件与敏感信息，补充必要忽略规则。
2. Codex 按明确范围暂存并建立前端基线提交，记录提交号。若 Git 缺姓名/邮箱，由你提供作者信息，不代填身份。
3. 你在 GitHub 建立空的私有仓库。已有本地项目时，不额外初始化远程 README、`.gitignore` 或 License。
4. 提供仓库地址，由 Codex 连接 `origin` 并推送；GitHub 登录由你完成，不把访问令牌发进聊天或写进远程 URL。
5. 你打开 GitHub，确认能看到最新提交、源代码和文档。
6. 从另一个临时目录克隆，按锁文件安装并构建，确认仓库可复现。先克隆，避免以后只下载散落的源码文件。

每个已验收小任务建立一次提交。你负责合入 `main`，功能开发使用如 `feat/auth`、`feat/posts` 的分支。A、B 在各自副本修改，合并前先检查，不同时覆盖同一个工作目录。

日常顺序：同步最新代码、完成一个任务、检查差异、运行适用检查、提交、推送、核对远程结果。有本机未提交修改时，先保存和检查，不直接强制覆盖或盲目拉取。

继续使用现有 Next.js + TypeScript + Tailwind。前端、后端接口可放在同一个项目，初版不需要再起一个独立后端仓库或额外买一台服务器。Next.js 服务端处理登录、权限和业务，服务端连接数据库。

建议关系：浏览器访问网页和受控接口，Next.js 服务端读取会话、校验权限，再操作 PostgreSQL 或对象存储。密码哈希、数据库连接串和存储管理密钥仅在服务端使用。

数据库访问初选 Prisma；认证库在 S07A 做兼容验证后锁定。现有 Auth.js Credentials 候选支持 ID/密码校验，但不替项目完成注册、密码哈希和限流，且该模式采用 JWT 会话时必须额外设计服务端撤销检查。Better Auth 的普通 username 插件注册示例仍要求 email，不能直接套模板或给用户虚构邮箱。选型必须通过纯 ID+密码、退出、改密撤销、封禁以及部署兼容性验收，不为适配库而改变产品规则。

本机已验证 Node 26.13.1；所查 Vercel 文档列出 24.x、22.x、20.x。G03 要选并验证双方支持的 Node LTS 主版本，例如先验证 24.x，再同步本地、CI 和部署配置。不能用“本机能跑”替代托管环境验证。

## 8. 每一步完成时，你怎么判断 AI 做对了

每次收到“完成”后看这五项：

1. 能打开的页面或能执行的结果，给出具体点击顺序。
2. 适用自动检查与真实结果，区分单元测试、数据库集成测试和浏览器验证。
3. 失败与权限场景，例如游客不能写、B不能删A、断网不丢草稿。
4. `docs/verification` 中的证据，进度清单只更新当前已完成项。
5. 检查过的代码差异、提交号和远程同步状态。数据库和媒体备份另行记录，不能用 Git 提交替代。

通用复核提示词：

```text
复核刚完成的【编号】：检查它的实际改动、适用自动检查及至少一条浏览器操作链路，再检查一条失败或越权场景。依据真实结果列通过/失败/未测试，不只复述实现。确认没有无关改动、秘密入库或真实模式假数据回退。
```

按用户最新安排，当前下一步为S07B本地数据库。上文G01～G03/P01作为后置准备任务保留，在需要代码托管与云部署时执行。
