## 实际验证

| 检查 | 结果 |
| --- | --- |
| lint、Next 路由类型生成、TypeScript、44 项既有测试、生产构建 | 通过；新 API 使用 Node Runtime，生成静态页面不读取真实库 |
| `npm.cmd run verify:s07b` | 14 项实际数据库测试，空库迁移重建和重复执行通过 |
| `npm.cmd run verify:s07c` | 13 组生产 HTTP/PostgreSQL 集成场景通过 |
| 真空库人物查询 | 200、空数组，无演示人物兜底 |
| 参数、游标、重复/未知参数 | 400；跨筛选复用游标拒绝 |
| ID keyset 分页、改名后翻页 | 无重复，末页 nextCursor=null |
| 停用/不存在人物及停用分类 | 列表过滤，详情 404 |
| 未登录、伪造身份头和演示 Cookie | 401 |
| 真实普通账号访问管理员入口 / 封禁账号 | 403；临时管理员只读 200 |
| 已撤销、过期、authVersion 不一致的真实库会话 | 401 |
| TCP 断连 / 数据库角色缺少 schema 权限 | 503，返回错误和 requestId，无 data；不泄露 SQL 或连接 |
| HEAD / OPTIONS / 业务写入方法 | 200 无正文 / 204 与正确 Allow / 405 |
| 客户端构建产物 | 未发现本机数据库密码或测试会话密钥 |
| 开发库账号、凭据、钱包、操作与流水计数 | 均为 0；公共人物 3 位，未导入浏览器演示数据 |

集成测试每次创建独立随机验证库，迁移后直接构造临时资料、账号和 iron-session 会话，启动真正的 Next 生产服务发 HTTP 请求。它证明授权读取入口，不是 S08 的注册/密码登录流程验收。验证结束停服务、移除本次验证库及临时探测角色。开发库和保留测试库不清空。

首轮发现数据库驱动的 schema 权限错误被包装在多层 cause/meta 中，不能只匹配顶层 Prisma code；已修复分类，复跑确认返回 503。原始异常只在服务端处理，客户端保持统一脱敏错误。
