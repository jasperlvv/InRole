## 自动验证

- `npm run check`：lint、TypeScript、46项规则测试、生产构建。
- `npm run verify:community`：22组独立临时PostgreSQL库、两个生产服务实例、受限应用账号的真实HTTP集成场景，详见 [结果](S09-S15-result.json)。包括并发领取、10余额两次同时投8仅一次成功、赠送幂等与双方余额/流水核对、实际作者权限、投票截止、头像权限、有效视频及伪造拒绝、Range读取、恢复码并发重放和隐藏传播。
- `npm run verify:s08`：24组认证回归；注册现在按S12规则在同一事务发放当日10通宝，旧“零余额注册”断言相应更新。
- `npm run verify:s07b`：16项数据库约束/权限测试、空库重建和重复迁移；8份迁移、33项CHECK、16个触发器、Prisma无漂移。
- `npm run verify:s07c`：13组读取、DTO、会话、断库、权限和客户端秘密检查；页面标记更新为“真实社区”。
- `npm audit --omit=dev`：未报告已知漏洞。
- `npm run backup:verify`：本机备份恢复到全新临时库，32张表（含迁移记录）数据摘要全部一致；备份在本机PostgreSQL目录下，未进入Git。见 [恢复证据](S17-local-restore-result.json)。

测试脚本只销毁本次随机创建的隔离测试库，不删除或重置开发库。迁移只追加，没有修改已执行文件。并发投币测试发现的PL/pgSQL变量歧义已用追加迁移修复。

## 限制与后续

- S16本地自动和浏览器检查完成；真实手机软键盘、Wi-Fi/蜂窝、慢网及真实多人体验未运行，仍是上线前验收项。
- 新真实社区主要使用中文界面；原演示外观和中英文设置保留，新功能词条的完整英文覆盖仍待补齐，不宣称全站已完成双语验收。
- 本机媒体使用受控文件存储；图片转WebP，GIF取首帧；视频最大30MiB、10分钟，限定可解析的MP4/WebM与常用视频编码。其他格式明确失败。未接云对象存储或平台定向分享。
- 推荐候选为最新1000篇，管理列表/个人活动每类最多50～100项；这是本地首版范围。未做大规模负载或推荐效果实验。
- 共享数据库支持多服务测试；真实多实例部署需共享媒体存储，不能使用各自临时磁盘。
- 云部署、正式库、域名、容器构建、正式媒体备份和5人真人内测未运行，按用户选择后置。部署及反馈材料见 [发布准备](../deployment-and-beta.md)。
