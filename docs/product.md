# InRole「入戏」产品规则 V0.2

更新：2026-11-23。S01～S06、前端内容扩展及主题/语言/阅读设置已实现；本文同时约定后续真实服务规则，服务端安全、事务与推荐要求尚未实现。证据见verification/S04-S06.md、verification/2026-11-23-frontend.md及verification/2026-11-23-appearance.md。

## 定位与范围

- 名称：入戏 / InRole；宣传语：换个身份，说你的话。
- 用户每次发言选择公共人物，通过帖子、话题、人物评价和通宝互动。
- 手机、平板、电脑使用同一响应式网页，暂不开发原生 App。
- 四个入口：帖子、热搜、人物、我的。人物页承载评分和投币，人物榜与帖子/话题热搜分开。
- 当前四大模块具备本机演示交互；S07～S18接入真实认证、数据库、接口、推荐与部署。

## 账号与访问

| 状态 | 可做什么 |
| --- | --- |
| 游客 | 浏览公开帖子、评论、热搜、话题、人物、评分、榜单、用户公开主页 |
| 登录用户 | 发帖、评论、点赞、评分、投币、举报；查看和管理自己的私有资料 |
| 管理员 | 在普通账号能力外管理人物、话题、举报、内容可见性和账号状态 |

- 互动入口统一引导未登录用户进入登录/注册，写接口也必须验证会话，不能仅隐藏按钮。
- 个人 ID 为公开的 @账号，不是证件号码。默认3～20位小写英文字母、数字、下划线；去首尾空白并转小写后做唯一校验。
- 注册只填 ID 和自定义密码，不要求邮箱、手机号或扮演人物。ID首版不可修改，显示昵称和简介可编辑。
- 密码8～64字符，不静默裁剪，不保存明文，不进入浏览器持久存储、日志或分析事件。
- 使用成熟认证库管理会话；服务器实现注册、密码哈希、限流、退出与改密。具体库在S07核实。
- 登录错误统一显示“ID或密码错误”。改密验证旧密码并撤销旧会话，退出后不再有写权限。
- 内测先做已登录改密；公开注册前另行实现恢复码或可选恢复渠道，不提供无效的邮件找回入口。
- 登录回跳只允许站内地址，保留草稿，但不自动代替用户发布、点赞或投币。

## 首次喜好引导

1. 注册成功建立会话，进入 `/onboarding`。
2. 展示8～12个兴趣标签，可选1～5项，也可以点击“暂时跳过”。
3. 完成或跳过都保存引导完成状态，再回原页面或首页。
4. 中断引导，下次登录继续；已完成不反复弹出；个人中心可修改喜好。
5. 喜好只影响内容推荐，不绑定扮演身份。无喜好或匹配不足时用热门、新鲜内容补足。

## 人物与发言

- 公共人物由管理员维护，用户不创建或占有人物；同一人物可以被多人选择。
- 当前演示库有22位公共人物、16条初始文字帖。11月23日新增的10条帖子、20条评论和示例点赞仍明确属于演示内容，不作为真实用户活动宣传；旧浏览器只追加一次，保留已有发言、互动、钱包及删除结果。
- 22张人物头像保存在本地public/people，页面统一调用PersonAvatar；原始作品、作者、许可和裁剪说明可从/people/credits及素材目录追溯。人物选择器、帖子、评论、榜单和设置预览共用头像映射。
- 每篇帖子、每条评论保存真实作者 ID 与本次人物 ID，不能从用户“当前人物”反推历史身份。
- 展示“人物名称 · @个人ID”及用户扮演标识；人物名进入人物页，@账号进入用户页。
- 发帖、评论时各自选人物；最近使用记录仅为便利功能。发布后作者和人物不可修改。
- 人物停用后不能用于新发言、评分、投币，历史内容保留；历史保留不等于违规内容不可隐藏。
- 评论为纯文字1～500个Unicode字符；帖子正文最多500字符，有图片、视频、投票或引用时允许省略正文，不能发布完全空白内容。
- 一帖可关联0～3个管理员维护的话题；一级评论。帖子扩展支持最多6张JPG/PNG/WebP/GIF（单张5MB），或1个MP4/WebM视频（30MB）；图片与视频分开发帖。暂不做私信或关注。
- 投票为单选，问题1～100字、2～4个不同选项（每项1～60字），有效期1/3/7天；每账号一票，换人物不能重复投，发布后不改选项，截止后停止投票。
- 引用保存原帖ID并提供原帖链接，不复制人物身份到新帖；新帖仍独立选择人物。原帖删除后只显示不可用提示，不泄露已删除正文。
- 帖子详情默认展示评论列表及简洁写评论入口，点击后才打开人物选择与评论表单。
- 每账号每帖一个赞，可取消，换人物不能多赞。自己的内容可删除，他人的不可删除。
- 发布失败保留草稿，重复请求不能产生多条内容；内容按纯文本渲染。
- 帖子和评论有稳定分页、加载、空、错误状态，不用演示数据掩盖真实请求失败。

## 搜索、人物申请、头像和分享扩展

- 广场顶部提供关键词搜索区，匹配正文、投票、人物、话题和@账号，显示结果数量、空状态、清空入口。当前是本机字符串匹配；搜索接口、分词、相关性和索引后续接入。
- 登录后申请公共人物：填写人物名称及基本信息，或只粘贴维基百科/百度百科词条链接；申请需审核，不能直接创建人物或占有人物。
- 名称最多60字，介绍最多1000字；百科链接只接受https维基百科/wiki/与baike.baidu.com/item/词条，移除查询和锚点；当前不自动抓取网址。重复申请按账号去重。
- 申请记录当前仅在本机待审核列表展示；真实审核与入库在S15实现。服务端后续仍需独立校验、限流和权限控制。
- 人物头像由管理员统一上传维护，普通用户的申请不修改公共头像；Person.avatarUrl及统一头像组件已预留，未配置/加载失败时显示汉字头像。真实上传、文件处理、存储、来源说明与审核在S15完成。
- 分享支持复制文案及浏览器系统分享；当前链接只指向本机演示，不能声称其他设备可读取本机内容。正式公开链接、平台卡片和微信/QQ定向接入在部署及平台配置后实施，不显示虚构发送成功。
- 本机媒体使用IndexedDB存Blob，localStorage只保存附件元数据和帖子；对象URL按展示创建/释放。清理浏览器媒体会令附件不可用，显示明确提示，不伪造图片或视频。

## 热搜与推荐

- 热搜有帖子榜、话题榜，支持最近24小时/7天，展示更新时间。
- 帖子热度=有效点赞账号数+3×独立评论账号数；排除作者对自己内容的互动。
- 话题热度=2×独立发帖账号数+独立点赞账号数+3×独立评论账号数；在话题内分别去重，排除对自己帖子的互动。
- 统计窗口内有效互动，不使用累计计数冒充近期数据；老帖有近期互动也可上榜。
- 隐藏、删除和无效数据退出公开排行；定时频率在S13按托管套餐配置。
- 首页提供推荐/最新；推荐V1使用兴趣匹配、新鲜度和热度，并加入少量探索内容。
- 后续基于脱敏曝光和真实互动升级推荐；先保留统一接口与算法版本，不提前引入机器学习服务。

## 人物评分与通宝

- 人物是公共评价对象；1～5分整数，一账号对一人物一份评分，可以修改或删除。
- 可附文字评价，按真实@账号展示，不另选扮演身份。修改评分不增加人数。
- 无评分显示“暂无评分”；至少5份有效评分才入榜，均分、人数、人物ID决定稳定排序。
- 每个未封禁账号每天首次有效登录/访问领取10通宝，按北京时间自然日唯一发放；持续登录用户第二天访问也能领。
- 余额可累积，失败可重试但不能重复发放；所有日期以服务端为准。
- 货币统一命名“通宝”（英文Tongbao），图标为圆形方孔钱，普通状态跟随其他文字和图标的中性灰阶；余额区、快捷数量、流水也共用普通容器颜色，不单独使用蓝色装饰。确认按钮与链接沿用全站操作样式。已赞爱心是红色语义状态，适配深浅主题。
- 正整数投给公共人物，不能超余额，投出不可撤回；不充值、不提现，不提供独立账号转账，不影响评分。
- 每个帖子可给实际贴主@账号赠送通宝，不能自赠、不能超余额；接收方由原帖实际作者决定，不由扮演人物或客户端输入决定。登录后主动选择数量并确认，游客引导登录且不自动代送。
- 赠送扣减送出方、增加贴主余额，双方钱包均显示流水和原帖入口；收到的通宝可以继续使用。帖子展示累计收到数量；人物投币与帖子赠送分别统计，不相互计入榜单。
- 同一赠送请求重试不得重复扣款或入账，参数冲突应报错；原帖删除保留已完成收支与请求记录，新赠送拒绝已删除的帖子。
- 真实服务阶段：扣余额、流水、人物收币，以及贴主赠送的双方余额均在数据库事务内完成，具备幂等与并发保护。当前本机演示的一条赠送记录同时决定双方收支，单次localStorage写入；尚未提供多设备/多标签页并发事务保证。
- 今日/累计投币榜与评分榜分开。钱包与流水仅本人可看，普通客户端不能直接修改余额。

## 个人中心与管理

- 个人中心：资料、我的帖子/评论/评分/点赞、喜好、钱包流水、改密和退出。
- 公开主页：公开资料与公开帖子，不返回密码哈希、钱包、权限或其他私密信息。
- 管理后台：人物/话题维护、举报处理、内容隐藏、封禁和审计日志。
- 隐藏内容不能通过直链、缓存榜单、推荐或接口重新公开；封禁后的已有会话不能继续写入。
- 演示模式与真实模式明确区分；演示种子不是实际用户活动。

## 外观与界面语言

- 全站只有一套墨蓝色强调：浅色采用中性灰白背景和白卡片，深色采用炭灰背景和深灰卡片；导航、按钮、选中态和评分使用同一色系，人物头像占位统一灰阶。错误和删除保留必要的红色语义。可选浅色、深色或跟随系统，并监听系统配色变化。
- 移除多种主题色选择；旧紫/绿/橙偏好自动归一为蓝色，其他设置保留。字号小/标准/大/超大；舒适/紧凑密度；减少动画。设置即时应用，保存到独立的inrole.ui.preferences.v1，不写社区内容或账号资料。最新配色证据见verification/2026-11-23-unified-palette.md，替代此前多色方案。
- 界面支持简体中文/英文。界面控件、导航、表单、状态和常用错误经显式词典翻译，不使用在线翻译，不改写帖子、评论、评价、投票文本、人物原名、账号昵称或简介。
- 游客也能调整本机外观，属于显示偏好；发帖、投票、资料编辑等业务写操作仍要求登录。偏好在退出后保留，目前不跨设备或按账号同步。
- 账号菜单从电脑左下、手机右上打开；提供本人中心、公开主页、钱包、喜好、界面设置、主题快捷切换、退出；菜单支持方向键/Home/End/Esc、外部点击关闭和焦点返回。
- 恢复界面默认仅重置显示偏好，不删除账号、草稿、帖子、媒体或钱包；存储失败时明确说明本次偏好只在内存有效。
