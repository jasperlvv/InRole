## S08A 验证

- 服务端归一化：`Primary_User` 和带首尾空格的同 ID 存为小写；三个并发的大小写/空格变体只成功一次，其他返回 409，数据库只有一份账号/钱包。
- 注册严格接收 handle/password，拒绝 email、role、userId、authorId；真实网页正好两项输入。超大体积 413、非 JSON 415、非法输入 400。
- 直接检查真实数据库：存储 Argon2id v19 / m19456 / t2 / p1；相同密码不同盐，Unicode 与首尾空格保留；初始钱包为 0，没有通宝操作。
- 登录不存在账号与错误密码的错误内容一致，均不签发 Cookie。真实会话可在第二个服务进程使用；同一浏览器重新登录后，旧 Cookie 被撤销。
- Cookie 为加密不透明 token、HttpOnly、SameSite=Lax、Path=/、生产 Secure/__Host-、Max-Age=604740、无 Domain；解密测试只发现 v/token，数据库保存 token 哈希。
- 退出先撤销数据库记录，旧 Cookie 在另一个实例 GET/PATCH 都返回 401；重复退出安全。其他设备会话不被单设备退出误撤销。
- 游客直接 PATCH 本人资料或 POST 改密返回 401；演示 Cookie 和 X-User-Id 不能取得权限。本人资料写入从会话决定作者，伪造另一用户 authorId/userId/role 返回 400，其他账号资料未变。
- 所有认证写入拒绝缺少或不可信 Origin；伪造转发 Host 不改变结果。
- 两个进程并发执行同 ID 的 12 次错误密码请求，8 次 401、4 次 429，数据库共享计数恰为 8；更换伪造 IP 头无效，超限响应有 Retry-After。
- 钱包创建出现测试故障时，账号/凭据/会话一起回滚。缺少限流密钥、可信代理配置不完整和数据库断连均拒绝，不回退演示数据；断连退出返回 503 且不清 Cookie 假报成功。

## S08B 验证

- 错误旧密码不改变凭据哈希、authVersion 或会话；伪造修改目标 userId 被拒。
- 改密成功后哈希更新、authVersion 增加，全部旧会话在同一事务撤销；旧 Cookie 不能再读/写，旧密码登录失败，新密码登录成功。
- 两个实例同时用同一个旧会话改密，只有一个请求 200，另一个 401。
- 对已完成旧密码哈希验证、正在等待账号行锁的登录请求，在测试库提交新哈希/版本；登录解锁后返回 401，未使用旧快照签发新会话。
- 账号封禁后旧 Cookie 不能写，登录被拒；解除封禁也不会使旧 Cookie 恢复。数据库触发器保证版本推进及会话撤销。
- 对已通过前置鉴权、正在等待账号锁的本人资料写入，分别在测试库撤销会话和封禁账号；排队写入解锁后分别返回 401/403，资料未改变。

## 浏览器与证据

本机浏览器用新生成的 QA 账号实际注册，注册只输入 ID 和密码，随后真实 Cookie 自动登录。资料保存后重新加载依然存在。退出后错误密码登录出现“ID 或密码错误”，正确密码可登录；再次退出并直接访问 `/live/me`，显示需登录且不显示私有表单。

浏览器没有自动提交改密表单，改密及旧会话拒绝由上述真实生产 HTTP/数据库测试验收；没有把 UI 显示退出当作会话撤销证据。QA 账号、零余额钱包、凭据和会话已在退出后按唯一测试标记清理，其他账号不动。
