入口使用本轮验收记录的候选预览地址；`/`真实社区，`/demo`独立演示。使用自己新建的验收账号；注销专门创建的可丢弃账号，不操作需要保留的用户或数据。表格填写通过/失败/未做，并记录设备、系统、浏览器、网络和日期。
