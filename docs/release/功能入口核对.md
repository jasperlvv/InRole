# 0.2.0-rc.1 功能与入口核对

2026-11-25。以原版展示组件与现有真实业务为基础，本次没有重画整体界面。下表“接通”指源码与必要接口检查，视觉、触控和逐像素一致性仍需人工检查，不据此宣称已验收。

| 功能 | 真实入口/实现 | 本轮状态 |
| --- | --- | --- |
| 首页、推荐/最新、搜索、话题、分页 | `/`、`/live`、StageFeed | 接通，根路径移出演示Provider |
| 原前端演示 | `/demo`及既有演示子路由 | 原首页内容保留；演示品牌/首页导航、登录和引导回跳修正 |
| 注册/登录/喜好/改密/恢复码 | `/live/register`、`/live/login`、`/live/onboarding`、`/live/me`、`/live/recovery-codes` | 接通；注册仍只接受ID+密码 |
| 发帖、媒体、投票、引用 | `/live/compose` | 接通；草稿按真实账号保存于sessionStorage，失败保留 |
| 帖子、独立人物评论、分享、举报 | `/live/posts/:id` | 接通；复制/系统分享需人工实测 |
| 人物、评分、头像来源 | `/live/people`、`/live/people/:id` | 接通；公共目录22位，素材来源记录保留 |
| 每日通宝、投币、赠送与流水 | `/live/wallet`、人物/帖子确认弹窗 | 接通；事务/并发/幂等通过既有集成 |
| 热搜、榜单、兴趣推荐 | `/live/trending`、`/live/rankings`、首页 | 接通；V1规则推荐，未新增算法功能 |
| 个人活动、喜好、资料、外观 | `/live/activity`、`/live/preferences`、`/live/me`、`/live/settings` | 接通，主要布局继续复用 |
| 人物申请、举报、管理与审计 | `/live/request`、`/live/admin` | 接通；普通账号权限检查保留 |
| 按账号屏蔽 | 帖子/评论/公开主页；`/live/account-controls`解除 | 本轮新增；列表私有，双方登录后内容和互动受限；游客仍可阅读公开内容，统计汇总不变 |
| 注销与数据处理 | `/live/account-controls`、`/delete-account` | 本轮新增；密码验证、事务回滚、所有会话撤销、数据去标识和媒体清理有集成证据 |
| 联系/政策 | 页脚、`/contact`、`/privacy`、`/terms` | 本轮新增，使用用户明确提供的运营者和邮箱；托管区域和正式保存策略待第2步确定 |
| 服务健康 | `/api/health`、`/api/ready` | 本轮新增；健康与数据库就绪分离，不返回秘密 |

素材核对：目录头像使用本地文件，保留`public/people/SOURCES.md`及公共来源信息，包含公共领域与CC BY-SA等许可记录。实际素材/许可证原始真实性未在本轮逐一联网重新审定；Logo为用户此前提供的素材，公开运营前由运营者确认持有使用权。没有把用户上传来源等同于平台已经取得全部授权。

未做：真实手机/电脑视觉与软键盘、正式HTTPS、云端容器、大陆/海外连通性、真人体验。英文、PWA、移动端和额外社交功能继续后置。
